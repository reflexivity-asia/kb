Reflexivity Insights 不只呈现市场或公司的单条标题，而是把变化继续连接到相关公司、主题、敞口、后续验证点以及下一步研究问题。

一个典型的 Insight 可以按以下顺序阅读：

1. **信号** — 发生了什么变化，市场如何反应
2. **主要结论** — 这一变化带来的直接研究含义
3. **Reflexivity Graph** — 相关公司、主题、敞口与传导路径
4. **下一步关注点** — 哪些证据可以确认或修正当前判断
5. **继续向 Alfred 提问** — 从已展示的分组继续深入研究
