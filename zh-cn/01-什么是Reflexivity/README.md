# 什么是 Reflexivity？

**语言：** [English](../../en/01-what-is-reflexivity/README.md) · [日本語](../../ja/01-Reflexivityとは/README.md) · [한국어](../../ko/01-Reflexivity란/README.md) · **简体中文** · [繁體中文（台灣）](../../zh-tw/01-什麼是Reflexivity/README.md) · [繁體中文（香港）](../../zh-hk/01-什麼是Reflexivity/README.md)

[← Reflexivity 知识库](../README.md)

投资研究面临的问题，已经不再只是信息不足。更难的问题是判断什么重要、连接来自不同来源的证据，并及时形成有差异化的投资观点。

## 研究问题正在改变

机构研究流程仍然经常依赖大量手工操作，分散在不同工具和数据源中，整体速度也不够快。分析师需要花很多时间查找、整理和验证数据，真正用于提出问题和解释结果的时间反而受到挤压。

与此同时，许多现有工具都要等用户先提出问题或输入搜索词才会行动。当投资者已经知道该查什么时，这些工具很有用；但对于尚未想到要调查的关系、变化和二阶影响，它们帮助有限。

## 数据丰富，洞察稀缺

投资研究的主要约束正在从“能否获得信息”转向“能否生成观点并整合证据”。

优势越来越来自两个方面：

- 提出更好的问题，并检验更多假设；
- 在投资者还没想到要问之前，就发现可能重要的信号。

因此，未来的研究并不只是更好的搜索，而是要降低提问成本、扩大可监测范围，并让原本可能被忽略的信号更容易被进一步研究。

## 从回答问题，到发现什么值得关注

Reflexivity 是面向机构投资者的 AI 投资研究平台。

平台的核心是 **Alfred** 和 **Knowledge Graph**。

- **Alfred** 是一个 AI 分析师，既可以调查投资者提出的问题，也会主动发现可能重要的发展变化。
- **Knowledge Graph** 是 Alfred 用来理解公司、产品、主题、地区和市场之间关系的智能层。

Reflexivity 的目标不只是返回信息，而是发现信号、理解它与其他实体和主题的联系，并通过分析、情景测试和历史模式比较来深入研究投资观点。

## Reflexivity 实际在做什么

Reflexivity 主要承担五类研究角色：

1. **发现投资者原本可能错过的内容。**  
   监测市场、公司和宏观信号，识别新的机会、风险和异常。

2. **理解这些信号如何相互连接。**  
   梳理公司、主题和地区之间的关系，寻找不明显的影响和二阶效应。

3. **用自然语言让复杂研究更容易使用。**  
   让投资者能够快速提问、调查想法并检验假设。

4. **自主研究投资观点。**  
   对投资者提出的假设和系统发现的信号进行分析、情景测试和历史模式比较。

5. **让判断依据可追溯。**  
   让分析建立在可信数据之上，保留来源可追溯性，并在证据不足时明确说明限制。

## 对用户而言会发生什么变化

改变的不只是回答速度，而是整个研究方式。

- **时间：** 大幅压缩过去需要数小时甚至数天的研究工作。
- **广度：** 覆盖更多公司、主题和信号。
- **深度：** 让过去因时间或成本过高而难以开展的分析变得可探索。
- **盲点：** 不只研究已经知道要找的东西，也帮助发现原本没有注意到的内容。
- **信任：** 可以检查结论背后的来源和证据。

## 一种不同的研究方式

Reflexivity 的价值可以从两个方向理解。

一方面是 **更好的自主分析**：投资者提出问题后，更快地完成研究，并连接更多证据。

另一方面是 **主动信号发现**：发现投资者还没有想到要寻找的风险、机会和关系。

两者都重要，但后者更能体现 Reflexivity 的出发点。Reflexivity 不只是要更好地回答问题，而是希望把 **“发现应该问什么”** 本身也变成研究流程的一部分。

最终，我们希望投资者能够检验更多假设，更早研究新出现的风险和机会，并更清楚地看到判断背后的证据。
