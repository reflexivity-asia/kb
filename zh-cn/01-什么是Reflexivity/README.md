# 什么是 Reflexivity？

**语言：** [English](../../en/01-what-is-reflexivity/README.md) · [日本語](../../ja/01-Reflexivityとは/README.md) · [한국어](../../ko/01-Reflexivity란/README.md) · **简体中文** · [繁體中文（台灣）](../../zh-tw/01-什麼是Reflexivity/README.md) · [繁體中文（香港）](../../zh-hk/01-什麼是Reflexivity/README.md)

[← Reflexivity 知识库](../README.md)

这是关于我们为何存在、又是如何走到今天的故事。

它不是一套固定话术，而是一段仍在不断发展的故事。

## 所有内容汇合在一起

投资领域的主要约束，已经从“能否获得信息”转向“能否迅速整合证据并形成差异化观点”。投资优势也正在从投资者已经提出的问题，延伸到在市场尚未广泛理解之前，能否率先发现重要信号。

从市场终端到通用大语言模型，大多数工具都要等用户先提问。用户提出问题后，它们会检索信息，但对于投资者尚未想到要调查的关系和新出现的发展变化，往往保持沉默。许多价值最高的信号因此仍然隐藏着。

Reflexivity 是为弥合这一差距而打造的机构投资者研究平台。其核心是始终在线的 AI 分析师 **Alfred**。Alfred 利用 Reflexivity 的 **Knowledge Graph**，梳理公司、产品、主题和市场之间有证据支持的关系。它会主动发现重要变化；当投资者提出问题时，也可以在数分钟内完成复杂分析并测试投资情景。

每一项输出都建立在可信的机构级数据之上，并可追溯到其底层来源。当所需数据不存在时，Alfred 会明确说明限制，而不是生成没有依据的数字或结论，从而让投资者继续掌握“什么值得信任”的判断权。

最终，研究工作流会发生根本变化。投资者可以检验更多假设，在风险和机会登上新闻头条之前发现它们，并在日益复杂的市场中做出更有把握的决策。

## 现在的方式，哪里已经不再有效

1. 机构研究流程仍然大量依赖手工操作，分散且缓慢。分析师大部分时间都花在寻找和整理数据上，只能用剩余时间去做更高价值的工作——提出问题和解释答案。
2. 现有工具（Bloomberg、AlphaSense、Claude、GPT）会返回搜索结果、信息片段，有时也会产生幻觉。答案并不总是可靠，而且缺少市场语境。
3. 大多数工具都在等待用户提问，因此那些 “unknown unknowns”——也就是连自己该找什么都不知道的领域——依然无法被发现。
4. 即使是经验丰富、尝试用 Claude 或 ChatGPT 配合 MCP 和 API 自建 AI 工作流的投资者，也会反复遇到相同的问题：实体解析、凭空生成的输出，以及如何找到正确的标的范围，都需要不断调试。

## 数据很多，洞察很少

1. 投资领域的主要约束已经从信息获取转向观点生成。真正的优势如今主要来自两个地方：**投资者选择提出什么问题**，以及 **在他们想到要问之前，有什么答案或信号先被发现**。
2. 过去因为提问和验证的成本太高，大多数假设并没有真正得到检验。因为持续监控一切的成本太高，大多数盲点也一直存在。
3. 更有竞争力的投资者会不断降低提问成本，并让原本可能错过的信号实时来到自己面前。
4. 研究的未来不在于更好的搜索，而在于**自主分析和差异化观点**。

## Reflexivity 实际在做什么

1. **发现投资者原本会错过的内容。**  
   监测市场、公司和宏观信号，发现新出现的机会、风险和异常。
2. **理解这些信号如何连接。**  
   梳理公司、主题和地区之间的关系，识别不明显的影响和二阶效应。
3. **自主研究投资观点。**  
   通过分析、情景测试和历史模式匹配，评估系统发现的信号以及投资者提出的假设。
4. **通过自然语言让复杂研究更容易使用（Alfred）。**  
   让投资者可以像提问一样快速地探索问题、调查观点并检验假设。
5. **提供可追溯的判断依据。**  
   提供有来源支持、可审计的分析，让投资者能够更有信心地行动；同时通过 Alfred 提供有来源支持的推理和后续分析。

## 使用 Reflexivity 后，研究方式会如何改变

使用 Reflexivity 带来的变化，不只是研究速度更快。整个研究流程会在以下五个方面发生变化。

- **时间** — 大幅缩短过去需要数小时或数天的研究工作。
- **广度** — 覆盖更多公司、主题和信号。
- **深度** — 过去难以触及的分析也可以进一步探索。
- **盲点** — 发现原本并没有主动寻找的变化。
- **信任** — 在追踪和验证来源的基础上，做出更有把握的判断。

## Reflexivity 的特点

### 对市场关系进行结构化理解

Knowledge Graph 对现实世界中的关系建模，包括竞争对手、产品、地缘政治事件和主题暴露。其他工具返回信息和关键词匹配；Reflexivity 则揭示隐藏的暴露与机会，并提供可用于投资策略的预测性洞察。

### 不只是按需回答，而是主动提供信号

实时发现投资者原本不会自行找到的催化因素、财报影响和市场机制转换。其他工具依赖查询或提示词；Reflexivity 会持续监测并在需要时介入。

### 在可信数据之上进行推理

直接在一个平台中原生整合并使用机构级数据集，包括 S&P Global、LSEG、Cboe、Nasdaq 和 Refinitiv。

每一项输出都可以追溯到原始来源，并完整查看支撑底层分析的来源信息。

与通用 AI 不同，Reflexivity 的设计目标是**暴露不确定性，而不是生成听起来合理的答案**。

**对投资者的价值：** 更快的信号发现、更好的分析、更有把握的观点生成。

## Reflexivity、Alfred 与 Knowledge Graph

**Reflexivity 是面向机构投资者的 AI 投资研究平台。**

它把市场情报、关系映射和按需分析带到同一个研究环境中。

### Alfred

始终在线的 AI 分析师，会主动发现重要内容，也会调查投资者提出的问题。

### Knowledge Graph

Alfred 用来理解关系、识别受影响公司或主题，并发现二阶影响的 Reflexivity 专有智能层。

## 从主动发现，到更深入的分析

### 发现原本没有在寻找的内容

Reflexivity 帮助投资者发现那些他们原本根本不会想到去寻找的信号、风险和机会。

### 深入研究已经提出的问题

当投资者带着问题来到 Reflexivity 时，平台会帮助他们更快、更准确、更有把握地找到答案。

这两种方式并不是彼此分开的功能。Reflexivity 可以在投资者提问之前先发现可能重要的内容，也可以在问题出现之后继续深入研究，把两者连接成一个完整的研究流程。
