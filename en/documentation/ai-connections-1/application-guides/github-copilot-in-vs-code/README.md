# GitHub Copilot in VS Code

## Connect with GitHub Copilot in VS Code

**Draft:** This setup path still needs connection testing.

VS Code can connect to a remote MCP server from your user profile or workspace. A managed organization may first need to allow the server.

The configured production target uses Streamable HTTP:

`https://api.reflexivity.com/external-research-mcp/mcp`

Use [VS Code's MCP setup guide](https://code.visualstudio.com/docs/agent-customization/mcp-servers) for the application's connection controls. Reflexivity-specific sign-in and verification steps will follow validation.

Using Copilot from a terminal? See [GitHub Copilot CLI](../github-copilot-cli/README.md).
