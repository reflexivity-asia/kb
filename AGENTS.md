# Agent Instructions

## AI attribution policy
<!-- AI_ATTRIBUTION_POLICY_V1 -->

Do not add AI/tool generator attribution to repository artifacts.

- Do not add `Co-Authored-By` trailers identifying Claude, ChatGPT, Codex, an AI model, vendor, bot, or other AI tool.
- Do not add `Generated by`, `Generated with`, `Created by`, `Assisted by`, AI signatures/badges, session URLs, or equivalent attribution.
- This applies to commits, pull requests, Issues, comments, documentation, handoffs, changelogs, release notes, and generated files.
- Keep durable artifacts focused on the work and its evidence, not the generating tool.
- Only add AI/tool attribution when Jim explicitly requests it in the current task.
