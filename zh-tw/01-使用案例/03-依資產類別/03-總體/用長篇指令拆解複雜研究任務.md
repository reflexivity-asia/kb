## 何時適合使用這種方式

面對範圍很廣的研究主題，如果只下「分析這個主題」這類一句話指令，研究範圍、比較框架與希望得到的最終結論都可能不夠清楚。

原資料展示另一種做法：在研究指令本身就寫清楚**要比較什麼、依什麼順序調查，以及最後希望用什麼格式做決策整理**。

長 prompt 的目的不是文字多，而是拆解。當指令明確定義以下四件事，複雜研究會更容易控制：

1. 目標產業或實體；
2. 共通評估維度；
3. 地理位置、價值鏈曝險等二階影響；
4. 最後的綜合格式，例如矩陣或優先順序清單。

## 範例 1：跨產業比較去碳化需求

原始 prompt 要求在全球範圍比較電力、石油與天然氣、鋼鐵、水泥、化學、運輸、農業與建築，並指定共同研究順序：

- Scope 1/2/3 絕對排放量與排放強度；
- 技術減排路徑與成熟度；
- 可取得時使用邊際減排成本曲線；
- 區域政策風險；
- 對供應商、客戶與替代風險的二階影響；
- 最後建立優先矩陣，區分最大排放者與最難減排產業。

重要的設計是這個推進順序：

**排放規模 → 減排技術 → 減排成本 → 政策差異 → 價值鏈 → 優先排序。**

這讓「排放最大」與「最難去碳」在最後綜合前維持為兩個不同問題。

原始材料連到一個私有 Research 結果。本公開頁面**不重建不可存取的輸出**。

## 範例 2：從事件擴展到受影響公司

原資料也提供大型企業事件的 prompt 模式，包括計畫中的大型美國 IPO。

研究指令可以明確依序處理：

**事件 → 直接受益 / 負面受影響公司 → 歷史類比 → 更廣泛市場影響。**

這比只問「哪些公司跟這件事有關」更有用，因為它直接定義如何把事件翻譯成研究地圖。

## 範例 3：用歷史事件找出目前可能受益者

另一個 prompt 以過去五屆足球世界盃作為證據基礎，詢問哪些美國與日本公司或產業可能從世界盃受益。

順序刻意設計為：

**歷史案例 → 重複出現的受益模式 → 把模式套回目前美國與日本市場。**

這可以降低沒有歷史驗證、直接從當前事件想像受益者的風險。

## 範例 4：把政治事件拆成多個情境

原資料包含一個範例：先建立 **2026 年美國期中選舉**的多種可能情境，再分析不同情境可能如何傳導到美國經濟與股票市場。

這個 prompt 設計的重點不是假定某一種選舉結果，而是**先定義多種情境，再分別追蹤各情境下的經濟與市場傳導路徑**。這是一個研究結構範例，**不是對任何政治結果的預測、背書或偏好**。

## 如何使用這個工作流程

處理複雜主題時，重點不是寫很長的一段文字，而是在研究開始前把四件事講清楚：

**範圍 → 比較維度 → 調查順序 → 最終輸出。**

如果最後研究結果偏離使用者意圖，這個結構也更容易找出問題到底出在範圍漏掉、比較維度不足，還是綜合格式不對。

## 本使用案例說明了什麼

這個工作流程展示如何把研究流程直接設計進 prompt 裡，使複雜、多步驟分析仍然連結到最後的決策問題，而不是變成互不相干的事實集合。
