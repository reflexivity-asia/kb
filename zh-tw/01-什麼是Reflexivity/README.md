# 什麼是 Reflexivity？

**語言：** [English](../../en/01-what-is-reflexivity/README.md) · [日本語](../../ja/01-Reflexivityとは/README.md) · [한국어](../../ko/01-Reflexivity란/README.md) · [简体中文](../../zh-cn/01-什么是Reflexivity/README.md) · **繁體中文（台灣）** · [繁體中文（香港）](../../zh-hk/01-什麼是Reflexivity/README.md)

[← Reflexivity 知識庫](../README.md)

這是關於我們為何存在，以及如何走到今天的故事。

它不是一套固定話術，而是一段仍在持續發展的故事。

## 所有內容匯合在一起

投資領域的主要限制，已經從「能否取得資訊」轉向「能否快速整合證據並形成差異化觀點」。投資優勢也正在從投資人已經提出的問題，延伸到在市場尚未廣泛理解之前，能否率先發現重要訊號。

從市場終端到通用大型語言模型，大多數工具都要等使用者先提問。使用者提出問題後，它們會檢索資訊，但對於投資人尚未想到要調查的關係，以及新出現的發展變化，往往保持沉默。許多價值最高的訊號因此仍然隱藏著。

Reflexivity 是為了彌合這一差距而打造的機構投資人研究平台。其核心是持續運作的 AI 分析師 **Alfred**。Alfred 利用 Reflexivity 的 **Knowledge Graph**，梳理公司、產品、主題和市場之間有證據支持的關係。它會主動發現重要變化；當投資人提出問題時，也可以在數分鐘內完成複雜分析並測試投資情境。

每一項輸出都建立在可信的機構級資料之上，並可追溯到其底層來源。當所需資料不存在時，Alfred 會明確說明限制，而不是產生沒有依據的數字或結論，讓投資人繼續掌握「什麼值得信任」的判斷權。

最終，研究工作流程會發生根本變化。投資人可以檢驗更多假設，在風險和機會登上新聞頭條之前發現它們，並在日益複雜的市場中做出更有把握的決策。

## 現在的方式，哪裡已經不再有效

1. 機構研究流程仍然大量依賴人工操作，分散且緩慢。分析師大部分時間都花在尋找和整理資料上，只能用剩餘時間去做更高價值的工作——提出問題和解讀答案。
2. 現有工具（Bloomberg、AlphaSense、Claude、GPT）會回傳搜尋結果、資訊片段，有時也會產生幻覺。答案並不總是可靠，而且缺少市場脈絡。
3. 大多數工具都在等待使用者提問，因此那些 “unknown unknowns”——也就是連自己該找什麼都不知道的領域——依然無法被發現。
4. 即使是經驗豐富、嘗試用 Claude 或 ChatGPT 搭配 MCP 和 API 自建 AI 工作流程的投資人，也會反覆遇到相同問題：實體解析、憑空產生的輸出，以及如何找到正確的標的範圍，都需要不斷調整。

## 資料很多，洞察很少

1. 投資領域的主要限制已經從資訊取得轉向觀點生成。真正的優勢如今主要來自兩個地方：**投資人選擇提出什麼問題**，以及 **在他們想到要問之前，有什麼答案或訊號先被發現**。
2. 過去因為提問和驗證的成本太高，大多數假設並沒有真正得到檢驗。因為持續監看一切的成本太高，大多數盲點也一直存在。
3. 更具競爭力的投資人會不斷降低提問成本，並讓原本可能錯過的訊號即時來到自己面前。
4. 研究的未來不在於更好的搜尋，而在於**自主分析和差異化觀點**。

## Reflexivity 實際在做什麼

1. **發現投資人原本會錯過的內容。**  
   監測市場、公司和總體訊號，發現新出現的機會、風險和異常。
2. **理解這些訊號如何連結。**  
   梳理公司、主題和地區之間的關係，辨識不明顯的影響和二階效應。
3. **自主研究投資觀點。**  
   透過分析、情境測試和歷史模式比對，評估系統發現的訊號以及投資人提出的假設。
4. **透過自然語言讓複雜研究更容易使用（Alfred）。**  
   讓投資人可以像提問一樣快速地探索問題、研究觀點並檢驗假設。
5. **提供可追溯的判斷依據。**  
   提供有來源支持、可稽核的分析，讓投資人能夠更有信心地行動；同時透過 Alfred 提供有來源支持的推理和後續分析。

## 使用 Reflexivity 後，研究方式會如何改變

使用 Reflexivity 帶來的改變，不只是研究速度更快。整個研究流程會在以下五個方面發生變化。

- **時間** — 大幅縮短過去需要數小時或數天的研究工作。
- **廣度** — 覆蓋更多公司、主題與訊號。
- **深度** — 過去難以觸及的分析也可以進一步探索。
- **盲點** — 發現原本沒有主動尋找的變化。
- **信任** — 在追蹤與驗證來源的基礎上，做出更有把握的判斷。

## Reflexivity 的特點

### 對市場關係進行結構化理解

Knowledge Graph 對現實世界中的關係建模，包括競爭對手、產品、地緣政治事件和主題曝險。其他工具回傳資訊和關鍵字比對；Reflexivity 則揭示隱藏的曝險與機會，並提供可用於投資策略的預測性洞察。

### 不只是按需回答，而是主動提供訊號

即時發現投資人原本不會自行找到的催化因素、財報影響和市場機制轉換。其他工具依賴查詢或提示詞；Reflexivity 會持續監測並在需要時介入。

### 在可信資料之上進行推理

直接在一個平台中原生整合並使用機構級資料集，包括 S&P Global、LSEG、Cboe、Nasdaq 和 Refinitiv。

每一項輸出都可以追溯到原始來源，並完整查看支撐底層分析的來源資訊。

與通用 AI 不同，Reflexivity 的設計目標是**揭示不確定性，而不是產生聽起來合理的答案**。

**對投資人的價值：** 更快的訊號發現、更好的分析、更有把握的觀點生成。

## Reflexivity、Alfred 與 Knowledge Graph

**Reflexivity 是面向機構投資人的 AI 投資研究平台。**

它把市場情報、關係映射和按需分析帶到同一個研究環境中。

### Alfred

持續運作的 AI 分析師，會主動發現重要內容，也會調查投資人提出的問題。

### Knowledge Graph

Alfred 用來理解關係、辨識受影響公司或主題，並發現二階影響的 Reflexivity 專有智慧層。

## 從主動發現，到更深入的分析

### 發現原本沒有在尋找的內容

Reflexivity 幫助投資人發現那些他們原本根本不會想到去尋找的訊號、風險和機會。

### 深入研究已經提出的問題

當投資人帶著問題來到 Reflexivity 時，平台會幫助他們更快、更準確、更有把握地找到答案。

這兩種方式並不是彼此分開的功能。Reflexivity 可以在投資人提問之前先發現可能重要的內容，也可以在問題出現之後繼續深入研究，把兩者連接成一個完整的研究流程。
