# 什麼是 Reflexivity？

**語言：** [English](../../en/01-what-is-reflexivity/README.md) · [日本語](../../ja/01-Reflexivityとは/README.md) · [한국어](../../ko/01-Reflexivity란/README.md) · [简体中文](../../zh-cn/01-什么是Reflexivity/README.md) · **繁體中文（台灣）** · [繁體中文（香港）](../../zh-hk/01-什麼是Reflexivity/README.md)

[← Reflexivity 知識庫](../README.md)

投資研究面臨的問題，已經不再只是資訊不足。更困難的是判斷什麼重要、連結不同來源的證據，並及時形成具有差異化的投資觀點。

## 研究問題正在改變

機構研究流程至今仍常依賴大量人工操作，分散在不同工具與資料來源中，整體速度也不夠快。分析師需要花很多時間尋找、整理與驗證資料，真正能用來提出問題與解讀結果的時間反而受到壓縮。

同時，許多現有工具都要等使用者先提出問題或輸入搜尋詞才會行動。當投資人已經知道該查什麼時，這些工具很有用；但對於尚未想到要調查的關係、變化與二階影響，它們能提供的幫助有限。

## 資料豐富，洞察稀缺

投資研究的主要限制正在從「能否取得資訊」轉向「能否產生觀點並整合證據」。

優勢愈來愈來自兩個方面：

- 提出更好的問題，並檢驗更多假設；
- 在投資人還沒想到要問之前，就發現可能重要的訊號。

因此，未來的研究不只是更好的搜尋，而是要降低提問成本、擴大可監測範圍，並讓原本可能被忽略的訊號更容易被進一步研究。

## 從回答問題，到發現什麼值得關注

Reflexivity 是面向機構投資人的 AI 投資研究平台。

平台的核心是 **Alfred** 與 **Knowledge Graph**。

- **Alfred** 是 AI 分析師，既能調查投資人提出的問題，也會主動找出可能重要的發展與變化。
- **Knowledge Graph** 是 Alfred 用來理解公司、產品、主題、地區與市場之間關係的智慧層。

Reflexivity 的目標不只是回傳資訊，而是發現訊號、理解它與其他實體與主題的連結，並透過分析、情境測試與歷史模式比較進一步研究投資觀點。

## Reflexivity 實際在做什麼

Reflexivity 主要承擔五類研究角色：

1. **發現投資人原本可能錯過的內容。**  
   監測市場、公司與總體訊號，辨識新的機會、風險與異常。

2. **理解這些訊號如何互相連結。**  
   梳理公司、主題與地區之間的關係，找出不明顯的影響與二階效應。

3. **用自然語言讓複雜研究更容易使用。**  
   讓投資人能快速提問、調查想法並檢驗假設。

4. **自主研究投資觀點。**  
   對投資人提出的假設與系統發現的訊號進行分析、情境測試與歷史模式比較。

5. **讓判斷依據可追溯。**  
   讓分析建立在可信資料之上，保留來源可追溯性，並在證據不足時明確說明限制。

## 對使用者而言會發生什麼改變

改變的不只是回答速度，而是整個研究方式。

- **時間：** 大幅壓縮過去需要數小時甚至數天的研究工作。
- **廣度：** 覆蓋更多公司、主題與訊號。
- **深度：** 讓過去因時間或成本過高而難以進行的分析變得可探索。
- **盲點：** 不只研究已經知道要找的東西，也幫助發現原本沒有注意到的內容。
- **信任：** 可以檢查結論背後的來源與證據。

## 一種不同的研究方式

Reflexivity 的價值可以從兩個方向理解。

一方面是 **更好的自主分析**：投資人提出問題後，更快完成研究，並連結更多證據。

另一方面是 **主動訊號發現**：發現投資人還沒有想到要尋找的風險、機會與關係。

兩者都重要，但後者更能體現 Reflexivity 的出發點。Reflexivity 不只是要更好地回答問題，而是希望把 **「發現應該問什麼」** 本身也變成研究流程的一部分。

最終，我們希望投資人能檢驗更多假設，更早研究新出現的風險與機會，並更清楚看到判斷背後的證據。
