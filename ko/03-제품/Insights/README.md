Reflexivity Insights는 시장과 기업의 변화를 단순한 헤드라인으로 끝내지 않고 관련 기업·테마·익스포저, 다음 확인 포인트, 후속 리서치 질문까지 하나의 흐름으로 정리합니다.

일반적인 Insight는 다음 순서로 읽을 수 있습니다.

1. **시그널** — 무엇이 바뀌었고 시장이 어떻게 반응했는지
2. **주요 포인트** — 변화에서 바로 읽을 수 있는 리서치 시사점
3. **Reflexivity Graph** — 관련 기업, 테마, 익스포저와 전파 경로
4. **다음 확인 포인트** — 해석을 확인하거나 수정할 수 있는 근거
5. **Alfred에서 이어서 조사하기** — 표시된 코호트를 출발점으로 한 후속 질문

이 페이지는 내용을 중복하지 않고 기존 유스케이스의 실제 리서치 사례로 연결합니다.
