# 什麼是 Reflexivity？

## 為甚麼需要 Reflexivity

投資領域的主要限制，已經由「能否取得資訊」轉向「能否快速整合證據並形成差異化觀點」。投資優勢亦正由投資者已經提出的問題，延伸至在市場尚未廣泛理解之前，能否率先發現重要訊號。

由市場終端至通用大型語言模型，大多數工具都要等使用者先提問。使用者提出問題後，它們會檢索資訊，但對於投資者尚未想到要調查的關係，以及新出現的發展變化，往往保持沉默。許多價值最高的訊號因此仍然隱藏著。

Reflexivity 是為了填補這一差距而建立的機構投資者研究平台。其核心是持續運作的 AI 分析師 **Alfred**。Alfred 利用 Reflexivity 的 **Knowledge Graph**，梳理公司、產品、主題和市場之間有證據支持的關係。它會主動發現重要變化；當投資者提出問題時，也可以在數分鐘內完成複雜分析並測試投資情景。

每一項輸出都建立在可信的機構級數據之上，並可追溯到其底層來源。當所需數據不存在時，Alfred 會清楚說明限制，而不是產生沒有依據的數字或結論，讓投資者繼續掌握「甚麼值得信任」的判斷權。

最終，研究工作流程會發生根本變化。投資者可以檢驗更多假設，在風險和機會登上新聞頭條之前發現它們，並在日益複雜的市場中作出更有把握的決策。

## 投資研究前線正在面對的問題

1. 機構研究流程仍然大量依賴人手操作，分散而且緩慢。分析師大部分時間都花在尋找和整理數據上，只能用剩餘時間去做更高價值的工作——提出問題和解讀答案。
2. 現有工具（Bloomberg、AlphaSense、Claude、GPT）會回傳搜尋結果、資訊片段，有時亦會產生幻覺。答案並不總是可靠，而且缺少市場脈絡。
3. 大多數工具都在等待使用者提問，因此那些 “unknown unknowns”——亦即連自己應該找甚麼都不知道的領域——依然無法被發現。
4. 即使是經驗豐富、嘗試用 Claude 或 ChatGPT 配合 MCP 和 API 自建 AI 工作流程的投資者，也會反覆遇到相同問題：實體解析、憑空產生的輸出，以及如何找到正確的標的範圍，都需要不斷調整。

## 數據很多，但把數據轉化為分析及決策仍然不容易

1. 投資領域的主要限制已經由資訊取得轉向觀點生成。真正的優勢如今主要來自兩個地方：**投資者選擇提出甚麼問題**，以及 **在他們想到要問之前，有甚麼答案或訊號先被發現**。
2. 過去因為提問和驗證的成本太高，大多數假設並沒有真正得到檢驗。因為持續監察一切的成本太高，大多數盲點亦一直存在。
3. 更具競爭力的投資者會不斷降低提問成本，並讓原本可能錯過的訊號即時來到自己面前。
4. 研究的未來不在於更好的搜尋，而在於**自主分析和差異化觀點**。

## Reflexivity 實際在做甚麼

1. **盡可能完整地找出投資者原本可能錯過的資訊及訊號。**  
   持續觀察市場、公司及宏觀環境，捕捉新的機會、風險及異常變化。

2. **找出分散訊號之間的連結。**  
   連結公司、產品、主題及地區之間的關係，不只辨識直接影響，也進一步發現不容易察覺的二階影響。

3. **把發現的想法快速轉化為分析。**  
   對系統發現的訊號或投資者提出的假設進行分析、情景檢驗及歷史相似模式比較。

4. **用自然語言快速深入複雜研究。**  
   可以像向 Alfred 提問一樣探索想法、繼續追問，並逐步檢驗假設。

5. **不只看到結論，也能核查結論背後的依據。**  
   分析結果可以追溯到原始數據及來源；如果證據不足，也會清楚說明限制。

## 使用 Reflexivity 後，研究方式會有甚麼改變

使用 Reflexivity 帶來的改變，不只是研究速度更快。整個研究流程會在以下五個方面發生變化。

- **時間** — 大幅縮短過去需要數小時或數天的研究工作。
- **廣度** — 覆蓋更多公司、主題及訊號。
- **深度** — 過去難以觸及的分析亦可以進一步探索。
- **盲點** — 發現原本沒有主動尋找的變化。
- **信任** — 在追蹤及驗證來源的基礎上，作出更有把握的判斷。

## Reflexivity 的特點

### 對市場關係進行結構化理解

Knowledge Graph 對現實世界中的關係建模，包括競爭對手、產品、地緣政治事件和主題曝險。其他工具回傳資訊和關鍵字比對；Reflexivity 則揭示隱藏的曝險與機會，並提供可用於投資策略的預測性洞察。

### 不等待提問，先捕捉可能重要的訊號

對於可能影響業績的變化、新的催化因素或市場機制轉換，Reflexivity 會主動尋找投資者原本未必會自行發現的訊號，而不是只等使用者輸入查詢或提示詞。

### 以可信數據作為分析及推理的依據

Reflexivity 將 S&P Global、LSEG、Cboe、Nasdaq 和 Refinitiv 等機構級數據集整合到同一個平台中，用於分析及推理。

每一項輸出都可以追溯到原始來源，並完整查看支撐底層分析的資料。

與通用 AI 不同，Reflexivity 的設計目標是**揭示不確定性，而不是產生聽起來合理的答案**。

### 對已經提出的問題繼續做更深入的分析

當投資者提出問題後，Reflexivity 可以連結相關證據、檢驗不同情景、比較歷史相似模式，並透過後續問題繼續深入研究。

**對投資者的價值：** 更快的訊號發現、更好的分析、更有把握的觀點生成。

## Reflexivity 的核心組成

**Reflexivity 是面向機構投資者的 AI 投資研究平台。**

它把市場情報、關係映射和按需分析帶到同一個研究環境中。

### Alfred

持續運作的 AI 分析師，會主動發現重要內容，也會調查投資者提出的問題。

### Knowledge Graph

Alfred 用來理解關係、辨識受影響公司或主題，並發現二階影響的 Reflexivity 專有智能層。
