## 甚麼時候適合使用這種方式

面對範圍很大的研究題目，如果只寫一句「分析這個主題」，研究範圍、比較方法及最終希望得出的決策格式都可能不清楚。

來源展示的是另一種做法：把**要比較甚麼、以甚麼次序研究，以及最後希望如何整理決策**直接寫進研究指示。

長 prompt 的價值不在於字數，而在於拆解。複雜研究若先明確定義以下四點，會較容易控制：

1. 目標行業或實體；
2. 共通的評估維度；
3. 地區、價值鏈等第二層影響；
4. 最終綜合格式，例如矩陣或優先次序清單。

## 範例 1：比較不同行業的脫碳需要

來源 prompt 要求對發電、石油與天然氣、鋼鐵、水泥、化工、運輸、農業及建築作全球比較，並指定共同研究次序：

- Scope 1/2/3 絕對排放量及排放強度；
- 技術減排路徑及成熟程度；
- 如有資料，加入邊際減排成本曲線；
- 地區政策風險；
- 對供應商、客戶及替代風險的第二層影響；
- 最後以優先矩陣區分「最大排放者」與「最難減排行業」。

關鍵設計是：

**排放規模 → 減排技術 → 減排成本 → 政策差異 → 價值鏈 → 優先排序。**

這樣可避免在研究早段把「排放最多」與「最難脫碳」混為一談。

原始材料連到一個私人 Research 結果。本公開頁面**不會重建或猜測該不可存取的輸出**。

## 範例 2：由事件擴展至受影響公司

來源亦提供大型企業事件的 prompt 模式，包括計劃中的大型美國 IPO。

研究指示可以明確依次處理：

**事件 → 直接受惠 / 受負面影響公司 → 歷史類似事件 → 更廣泛市場影響。**

這比只問「哪些公司與事件有關」更有用，因為它定義了如何把事件轉化成研究地圖。

## 範例 3：用歷史事件找出當前可能受惠者

另一個 prompt 問：參考過去五屆足球世界盃，哪些美國及日本公司或行業可能受惠？

次序刻意設定為：

**歷史案例 → 重複出現的受惠模式 → 把模式套用到當前美國及日本市場 → 再作公司層面的驗證。**

這可以減少未經歷史驗證、直接由當前事件臆測受惠者的風險。

## 範例 4：把政治事件先拆成多個情景

來源包含一個有關 **2026 年美國中期選舉**的例子，要求先建立多個可能情景，再分析各情景對美國經濟及股票市場可能產生的傳導。

這裡的研究設計原則，是**不要預設某一選舉結果**。先定義多個情景，再分別追蹤經濟與市場傳導渠道。這只是研究結構示例，**不是對任何政治結果的預測、背書或偏好表達**。

## 如何使用這套流程

處理複雜題目時，重點不是寫一大段文字，而是在研究開始前明確四件事：

**範圍 → 比較維度 → 研究次序 → 最終輸出。**

如果最後研究偏離使用者意圖，這個結構亦有助判斷問題究竟來自範圍遺漏、比較維度不足，還是綜合格式不合適。

## 本使用案例說明了甚麼

這套流程展示如何把研究程序本身設計進 prompt，使多步驟分析一直連接到最後的決策問題，而不是變成一堆互不相關的事實。
