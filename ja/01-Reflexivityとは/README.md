# Reflexivityとは？

**言語:** [English](../../en/01-what-is-reflexivity/README.md) · **日本語** · [한국어](../../ko/01-Reflexivity란/README.md) · [简体中文](../../zh-cn/01-什么是Reflexivity/README.md) · [繁體中文（台灣）](../../zh-tw/01-什麼是Reflexivity/README.md) · [繁體中文（香港）](../../zh-hk/01-什麼是Reflexivity/README.md)

[← Reflexivity ナレッジベース](../README.md)

投資リサーチの課題は、もはや単に「情報が足りない」ことではありません。重要なのは、何を見るべきかを判断し、複数の情報をつなぎ合わせ、差別化された投資アイデアにつなげることです。

## リサーチの課題は変わっています

機関投資家のリサーチ業務には、今も手作業で分断された工程が多く残っています。データを探し、組み合わせ、確認することに時間を取られ、本来価値の高い問いの設定や結果の解釈に使える時間が限られがちです。

また、多くの既存ツールは、利用者が質問や検索をして初めて動きます。すでに何を調べるべきか分かっている場面では有効ですが、まだ調べる発想に至っていない関係性や変化、二次的な影響を見つけることには限界があります。

## データは豊富でも、インサイトは不足する

投資における制約は、情報へのアクセスから、アイデアの創出と証拠の統合へ移りつつあります。

優位性は次第に、次の2点から生まれます。

- より良い問いを立て、より多くの仮説を検証すること
- まだ問いを立てる前に、重要なシグナルを見つけること

そのため、これからのリサーチに必要なのは単なる「より良い検索」ではありません。問いを立てるコストを下げ、監視できる範囲を広げ、これまで見逃していたシグナルを調べやすくする仕組みが必要です。

## 質問に答えるだけでなく、重要なものを見つける

Reflexivityは、機関投資家向けのAI投資リサーチプラットフォームです。

中心にあるのが **Alfred** と **Knowledge Graph** です。

- **Alfred** は、投資家が持ち込んだ問いを調査すると同時に、重要になり得る変化を能動的に見つけるAIアナリストです。
- **Knowledge Graph** は、企業、製品、テーマ、地域、市場の関係を理解するためにAlfredが利用するインテリジェンス層です。

Reflexivityは情報を返すだけではなく、シグナルを見つけ、そのシグナルが何とつながっているかを理解し、分析・シナリオ検証・過去パターンとの比較を通じてアイデアを深掘りすることを目指しています。

## Reflexivityが実際に行うこと

Reflexivityの役割は大きく5つあります。

1. **投資家が見逃しやすいものを見つける。**  
   市場、企業、マクロのシグナルを監視し、新たな機会、リスク、異常を捉えます。

2. **シグナル同士のつながりを理解する。**  
   企業、テーマ、地域の関係をたどり、直接的ではない影響や二次効果まで探ります。

3. **高度なリサーチを自然言語で扱えるようにする。**  
   投資家が質問し、アイデアを調査し、仮説を素早く検証できるようにします。

4. **アイデアを自律的に調査する。**  
   投資家が立てた仮説や発見されたシグナルについて、分析、シナリオ検証、過去パターンとの比較を行います。

5. **根拠をたどれる形で判断材料を示す。**  
   分析を信頼できるデータに基づかせ、出典を追跡できるようにし、根拠が不足している場合はその制約を明示します。

## ユーザーのリサーチはどう変わるか

変わるのは、単に回答が速くなることだけではありません。リサーチの進め方そのものです。

- **時間:** 数時間から数日かかっていた調査を大幅に短縮する
- **範囲:** より多くの企業、テーマ、シグナルをカバーする
- **深さ:** これまで手間やコストのため難しかった分析を試せるようにする
- **見落とし:** すでに探しているものだけでなく、まだ注目していないものを見つける
- **信頼:** 結論の根拠となる出典や証拠を確認できるようにする

## 異なるリサーチの進め方へ

Reflexivityの価値は、2つの方向から説明できます。

1つは **より良い自律分析** です。投資家が問いを投げると、より速く、より多くの根拠を伴って調査を進めます。

もう1つは **能動的なシグナル検出** です。投資家自身がまだ探そうとしていなかったリスク、機会、関係性を見つけます。

どちらも重要ですが、Reflexivityの出発点としてより特徴的なのは後者です。Reflexivityは、質問により良く答えるだけの仕組みではありません。**そもそも何を質問すべきかを見つけること**までリサーチの一部にしようとしています。

その結果、より多くの仮説を検証し、新たなリスクや機会をより早く調べ、その判断を支える根拠まで確認できるリサーチ環境を目指します。
