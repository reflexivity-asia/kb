# 運用資産別ユースケース

Reflexivityの調査・分析例を、実際の運用で扱う資産や市場から探せます。
同じユースケースが複数の資産クラスに関係する場合は、主な資産クラスに掲載し、関連する資産ページからも同じ記事をご案内しています。

## 資産クラス

- [株式](04-株式/)
- [債券](02-債券/)
- [FX](01-FX/)
- [マルチアセット](05-マルチアセット/)
- [マクロ](03-マクロ/)

### その他の資産

コモディティや暗号資産に関する例は、関連する株式・FX・マルチアセット・マクロのページからご覧いただけます。

## パートナー提供のユースケース

パートナーから提供されたユースケースも、内容に応じた資産クラスに掲載しています。現在掲載している株式会社QUICK提供のコンテンツには、各ページで提供元を自然な文章で示し、一覧では提供元と提供日を簡潔に表示しています。
元のメール本文に含まれる送受信者情報、顧客名、署名などは公開せず、共有された活用例の内容を公開用に整理しています。
