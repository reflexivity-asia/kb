Reflexivity Insights は、市場や企業の変化を単なる見出しで終わらせず、関連する企業・テーマ・エクスポージャー、次に確認すべき材料、追加の調査質問までつなげて整理します。

一般的な Insight は、次の流れで読むことができます。

1. **シグナル** — 何が変化し、市場がどう反応したか
2. **主なポイント** — その変化から直ちに読み取れること
3. **Reflexivity Graph** — 関連企業、テーマ、エクスポージャー、波及経路
4. **次に確認すること** — 見方を裏付けたり修正したりする材料
5. **Alfred で続けて調べる** — 表示されたコホートを起点にした追加調査
