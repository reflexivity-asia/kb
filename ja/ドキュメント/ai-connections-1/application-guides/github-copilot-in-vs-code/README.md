# GitHub Copilot in VS Code

[アプリケーション別ガイド](../README.md) · [ドキュメント](../../../README.md)

## GitHub Copilot in VS Codeと接続する

**ドラフト:** この設定方法は、まだ接続テストが必要です。

VS Codeでは、ユーザープロファイルまたはワークスペースからリモートMCPサーバーに接続できます。管理対象の組織では、先にサーバーの利用許可が必要な場合があります。

設定対象の本番環境はStreamable HTTPを使用します。

`https://api.reflexivity.com/external-research-mcp/mcp`

アプリケーション側の接続設定については[VS CodeのMCPセットアップガイド](https://code.visualstudio.com/docs/agent-customization/mcp-servers)を参照してください。Reflexivity固有のサインイン手順と確認方法は、検証完了後に追記します。

ターミナルでCopilotを使う場合は[GitHub Copilot CLI](../github-copilot-cli/README.md)を参照してください。
