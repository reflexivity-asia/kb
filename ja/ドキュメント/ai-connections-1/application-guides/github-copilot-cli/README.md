## GitHub Copilot CLIと接続する

**ドラフト:** この接続方法は、まだ接続テストが必要です。

Copilot CLIはリモートMCPサーバーに接続できます。組織のレジストリや許可リストのポリシーによって、ユーザーが追加できるサーバーが制限される場合があります。

設定対象の本番環境はStreamable HTTPを使用します。

`https://api.reflexivity.com/external-research-mcp/mcp`

接続設定については[GitHubのMCPセットアップガイド](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers)を参照してください。Reflexivity固有のサインイン手順と確認方法は、検証完了後に追記します。

エディター内でCopilotを使う場合は、GitHub Copilot in VS Codeを参照してください。
