# Reflexivity ユースケース

Reflexivityの調査・分析例を、**運用者別**または**運用資産別**の2つの切り口からご覧いただけます。

## 運用者別

[利用者・運用スタイルから探す →](運用者別/README.md)

ウェルスマネジメント / RIA、ヘッジファンド、ロングオンリー・アセットマネージャーなど、利用者や運用スタイルごとにユースケースを紹介しています。

## 運用資産別

[扱う資産・市場から探す →](運用資産別/README.md)

株式、債券、FX、マルチアセット、マクロなど、実際の調査で扱う資産・市場ごとにユースケースを紹介しています。同じユースケースが複数の運用者タイプや資産クラスに関係する場合は、それぞれのページから同じ記事をご覧いただけます。

> 掲載している数値や市場環境は、それぞれの調査・提供日時点のものです。現在の投資判断に利用する場合は、最新データとあわせてご確認ください。

## 提供元

Reflexivityが作成した調査事例に加え、パートナーから提供された活用例も掲載しています。

**株式会社QUICK提供**のページには、冒頭に著者と提供日を明記しています。元のメールに含まれる顧客名、宛先、メールアドレス、署名などは除きつつ、質問、分析の流れ、図表、結論はできる限り元資料の流れを保って掲載しています。

## 出典・元資料

掲載しているユースケースは、Reflexivity上で生成された調査事例と、パートナーから提供された活用例をもとに整理しています。

元資料の確認、出典、元ファイルへのアクセスに関するお問い合わせは **jim@reflexivity.com** までご連絡ください。
